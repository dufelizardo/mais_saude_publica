# User manual

> **Version:** 1.15.0 · [Português](../pt-BR/README.md)

This manual is for people who use Mais Saúde Pública at work: reception, nursing, physicians, pharmacy, regulation, surveillance
and management. It explains the screens in the order of the menu. Screen names, buttons and messages are quoted as they appear in
the application, in Portuguese, followed by a translation.

**Start here:** [Getting started](./00-primeiros-passos.md): signing in, the password, the menu, the profile and the unit, how
screens work and the most common messages.

## How each screen is described

Each screen is described in four parts:

- **What it is for:** the problem the screen solves at work.
- **Who uses it:** the profile needed to see the screen and its buttons.
- **Step by step:** what to do, in order.
- **Common messages:** the notice that may appear and what to do.

## Need help?

Ask your unit's coordination. Requests for access, a profile or a new password go to the system administration.
