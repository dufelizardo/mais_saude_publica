# Manual do usuário · User manual

- **[Português (pt-BR)](./pt-BR/README.md)**: o manual de quem usa o Mais Saúde Pública no dia a dia.
- **[English (en)](./en/README.md)**: the guide for people who use Mais Saúde Pública every day.

## Como este manual é mantido

As regras estão na [ADR-0222](../adr/0222-manual-do-usuario-bilingue.md):

- o português é a fonte, e o inglês espelha com os mesmos nomes de arquivo;
- cada arquivo começa pelo título e pela linha da versão da release que descreve, igual nas duas línguas;
- o PR que muda uma tela já coberta atualiza o texto nas duas línguas;
- a CI confere tudo isso com `.github/scripts/verificar_manual.py`.

## How this manual is maintained

The rules are in [ADR-0222](../adr/0222-manual-do-usuario-bilingue.md) (in Portuguese):

- Portuguese is the source, and English mirrors it with the same file names;
- each file starts with the title and the line with the release version it describes, the same in both languages;
- a pull request that changes a screen already covered updates the text in both languages;
- CI checks all of this with `.github/scripts/verificar_manual.py`.
