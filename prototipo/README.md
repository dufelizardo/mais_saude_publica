# Protótipo navegável

Telas estáticas de referência do Mais Saúde Pública: HTML puro, sem backend e com dados fictícios.
Servem de modelo visual para o frontend Angular (`frontend/`) e de "degustação" do sistema para
quem visita o repositório.

**Navegar:** https://dufelizardo.github.io/mais_saude_publica/

Publicado no GitHub Pages pelo workflow
[`prototipo-pages.yml`](../.github/workflows/prototipo-pages.yml) a cada mudança nesta pasta em
`developer`.

## O que saber antes de usar como referência

- **Não é o sistema real.** As telas já implementadas (por exemplo Login e Pacientes) seguem estes
  modelos, mas o frontend evolui separado e pode divergir. Números como "Versão 2026.1" e os
  indicadores são ilustrativos.
- **Dados fictícios.** Nomes, CPFs e números de cartão são inventados; nenhum CPF tem dígito
  verificador válido.
- `index.html` é a antiga "Landing Page.html", renomeada para abrir na raiz do site.
